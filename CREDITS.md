# Corn Souls — Third-Party Asset Credits

This file lists externally sourced assets **actually shipped** with Corn Souls. Asset selection, approvals, licensing evidence, and any future candidates are tracked in [assets/registry.json](assets/registry.json) under the rules in [ASSET_POLICY.md](ASSET_POLICY.md).

**No third-party models have been confirmed and registered as shipped under this new system yet.** This is not a declaration that every pre-existing asset in the game is original; a historical asset audit is still necessary.

When an asset ships, add its title, creator, source link, license and license link, modifications, and any required notices here. Keep those details consistent with the public [credits page](credits.html).

## Attribution template

**“Asset Title”** — by Creator ([source](https://example.com/)). [License Name](https://creativecommons.org/licenses/by/4.0/). Modifications: describe exactly what changed. No endorsement implied.

For CC0 assets, attribution is generally optional, but the project should still record provenance.
