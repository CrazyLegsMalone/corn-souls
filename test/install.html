Corn Souls TEST

This is the independent TEST app, not the stable Alpha release.

Install with Microsoft Edge on Android. Open Edge itself, paste this page's address into Edge's address bar, then use the Edge menu to select Install or Add to phone / Home screen.

Keep LIVE installed through Chrome. Chrome may refuse to install both versions from this same site.

Open the TEST game

This is a one-time installation. After that, launch TEST from its Edge-installed icon to get updates. No reinstall is needed for ordinary game updates.
